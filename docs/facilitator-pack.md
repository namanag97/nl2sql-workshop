# Facilitator pack

## Team & roles (3 facilitators for ≤ 30 attendees)

| Role | Owns |
|---|---|
| **Lead** (on stage) | Story, reveals, concept beats, timer, gates (S9, fallback call) |
| **Roamer ×2** | Table-level PIRA enforcement; never touch a keyboard — ask the Pilot to read aloud |
| Either roamer additionally | Wall-of-pain transcription (during Arc 3), loaner-laptop fleet |

Ratio rule: 1 facilitator per 8–10 attendees minimum. Below that, cut C8.

## Adjudication moves

1. **The reveal** — open envelopes only after every pair has posted numbers.
   Compare columns on the scoreboard; never shame a wrong number, ask its
   Pilot to name one decision the envelope assumed.
2. **The vote** — "whose revenue number is right?" Show of hands → answer:
   *the one whose decisions were declared.* D1–D3 is the proof.
3. **The attack** — Arc 3: pairs trade traps. Score = wrongness caught, not
   answers produced. Read out the best refusal of the room.
4. **The cliff** — read the room's own two scores (raw vs governed) before
   showing any external benchmark. Their numbers first, Spider 2.0 second.

## Failure-mode playbook (mirrors run-of-show contingencies)

| Signal | Move |
|---|---|
| ≥2 reds at smoke gate (S9) | Lead announces offline switch calmly: "we rehearsed for this"; DuckDB kit per runbook §D |
| Codex-wide errors | "intern answers" prints: pre-generated outputs, some wrong; judging exercise continues |
| Arc 2 behind at 1:40 | Cut Q5 + C8. Never cut the reveal or synthesis. |
| A pair finishes everything early | Hand them the next problem's ceiling prompt, not more floors |
| A pair stuck >6 min | Roamer runs the Inspect step aloud with the Pilot; if still stuck, loaner or merge pairs |
| Dominant attendee | Swap Pilot/Copilot roles at every question (already in the rules) |
| Energy dip at Arc 2 midpoint | Pull the reveal forward 5 minutes |

## Dry-run checklist (WP6, D-5)

- [ ] Full 150-min run with 2 stand-ins playing naive attendees
- [ ] Fallback switch rehearsed once mid-arc-1
- [ ] All 6 key envelopes verified against `keys.json` printout
- [ ] Wall-of-pain → eval export flow exercised end to end
- [ ] Timing log filled per segment; deviations > 3 min resolved in script
