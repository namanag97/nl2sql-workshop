# Scoresheet — print spec (one sheet per pair, A4, landscape)

The scoresheet is the physical spine of the room: every reveal compares
against what is written here. Keep fields big enough to read from 3 meters
(the scoreboard transcribe step depends on it).

```
MERIDIAN TRADING CO. — TEAM SCORESHEET        Pair ____  Table ____

Pilots: __________________ / __________________  (swap every question)

== ARC 1 — RAW TABLES =====================================
Q1  Total revenue, all time .......... ______________  (write the number)
Q2  Monthly x line x region — SUM of my table ... ______________
Q3  Active customers, March .......... ______________
Q4  Top customer: name ______________  amount ______________
Q5  Average order value .............. ______________

== ARC 2 — GOVERNED (after C6/C7) =========================
Our ticks:   D1 exclude cancelled? Y / N    D2 net of returns? Y / N
             D3 revenue date: ORDER / INVOICE
Q1' ______________   Q2' (sum) ______________   Q3' ______________
Q4' top: ______________ ______________   Q5' ______________

== ARC 3 — ADVERSARIAL ====================================
Our trap question (card # on the wall): ____
What the assistant did:  refused / answered with assumptions / confidently wrong
Our best catch, in one line: ______________________________

===========================================================
Envelope checklist (facilitator initials on each reveal):
Q1 [ ]   Q2 [ ]   Q3 [ ]   Q4 [ ]   Q5 [ ]
```

Print notes:

- Grid boxes ≥ 12 pt, high contrast; room lighting is hotel-grade.
- Arc 2 section is pre-printed with all five re-run fields so the score
  jump is visible on one sheet, old column vs new.
- The tick boxes D1–D3 are filled BEFORE C6 is pasted — the sheet forces
  the declare-then-run order. Facilitator line: "ticks first, then paste."
- Back of the sheet: the trap checklist (attendee-pack Sheet 3) — one less
  handout to lose.

Generation rule (WP7): the C0 "you should see" card and any count printed
anywhere must be generated from `data/out/manifest.json` at print time,
after the D-2 dataset freeze — never hand-typed.
